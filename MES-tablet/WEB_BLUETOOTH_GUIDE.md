我们已经为 MES-Tablet 添加了 **Web Bluetooth API** 支持！这意味着：

- ✅ **电脑浏览器（Chrome/Edge）** 可以直接连接蓝牙打印机
- ✅ **Android 手机 Chrome** 可以直接连接蓝牙打印机
- ✅ **无需打包 APP**，在开发环境就能测试蓝牙打印
- ✅ 自动检测环境，智能选择最佳蓝牙 API

## 📱 如何在浏览器中使用蓝牙打印

### 步骤 1: 准备工作

#### 硬件要求
- [ ] 一台**蓝牙标签打印机**（推荐佳博 GP-2120TF）
- [ ] 电脑或手机有**蓝牙功能**并已开启
- [ ] 打印机已**开机**且在配对模式（指示灯闪烁）

#### 软件要求
- [ ] 安装 **Chrome 浏览器**（版本 56+）
- [ ] 或安装 **Edge 浏览器**（Chromium 版本）

---

### 步骤 2: 启动前端服务

```bash
cd E:\YM_MES\MES-tablet
npm run dev:h5
```

访问地址：
- 电脑：`http://localhost:5175`
- 手机：`http://192.168.0.217:5175`（同一WiFi下）

---

### 步骤 3: 连接蓝牙打印机

1. 打开称重页面
2. 点击 **"🖨️ 连接打印机"**
3. **浏览器弹出系统对话框**选择设备：
   ```
   ┌─────────────────────────────────┐
   │     选择蓝牙设备                 │
   │                                 │
   │  ○ GP-2120TF (Printer)    ← 选择│
   │  ○ CP-2140                    │
   │                                 │
   │        [取消]    [配对]         │
   └─────────────────────────────────┘
   ```
4. 选择打印机 → 点击 **"配对"**
5. 授权权限 → 点击 **"允许"**
6. 连接成功！按钮**变绿色**

---

### 步骤 4: 打印标签

1. 选择工单 → 输入重量 → 提交报工
2. 点击打印按钮
3. 数据通过蓝牙发送到打印机
4. 🖨️ **打印完成！**

## 🔧 技术原理

### 工作流程

```
点击 "连接打印机"
    ↓
navigator.bluetooth.requestDevice()  // Web Bluetooth API
    ↓
浏览器弹出设备选择对话框（用户授权）
    ↓
用户选择设备
    ↓
device.gatt.connect()  // 建立连接
    ↓
获取服务和特征值
    ↓
characteristic.writeValue(data)  // 发送数据
    ↓
🖨️ 打印机打印标签
```

```javascript

  // 📱 APP → UniApp 蓝牙 API
}
```

## 🛠️ 常见问题

### Q1: 点击"连接打印机"没反应？

**检查清单**：
- [ ] 使用的是 Chrome/Edge 浏览器？
- [ ] 地址是 `localhost:5175`？（必须是 localhost）
- [ ] 电脑蓝牙已开启？
- [ ] 按 F12 查看控制台是否有错误？

### Q2: 找不到打印机？

**解决方法**：
1. 重启打印机（关闭电源，等5秒，再开）
2. 让打印机进入配对模式（长按电源键3秒）
3. 确保距离 < 10米
4. 刷新网页重试

### Q3: 连接成功但打印失败？

**调试步骤**：
1. 按 F12 打开开发者工具
2. 切换到 Console 标签
3. 重新执行打印
4. 查看红色错误信息
5. 根据错误提示排查
