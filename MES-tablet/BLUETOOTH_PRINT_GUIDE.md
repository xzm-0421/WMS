# 🖨️ MES-Tablet 蓝牙打印功能使用指南

## 📱 为什么 H5/网页不能用蓝牙？

### 技术限制说明

| 运行环境 | 蓝牙支持 | 原因 |
|---------|---------|------|
| **💻 电脑浏览器 (H5)** | ❌ 不支持 | Web 安全策略禁止访问硬件 |
| **📱 手机浏览器 (H5)** | ❌ 不支持 | 同上，浏览器沙箱限制 |
| **📲 微信小程序** | ⚠️ 有限支持 | 需要企业认证 + 特殊配置 |
| **📦 原生 Android APP** | ✅ **完全支持** | 可调用系统蓝牙 API |
| **📦 原生 iOS APP** | ✅ **完全支持** | 可调用 CoreBluetooth |

### 核心原因

```javascript
// 在浏览器环境中
typeof uni.openBluetoothAdapter  // → undefined（不存在）
navigator.bluetooth             // → 未实现或权限不足

// 浏览器安全模型：网页不能直接控制硬件设备
// 这是 W3C Web 安全标准的规定
```

## 🚀 如何启用蓝牙打印（打包成 APP）

### 方法 1: 使用 HBuilderX 可视化打包（推荐新手）

#### 步骤 1: 安装 HBuilderX

1. 下载地址：https://www.dcloud.io/hbuilderx.html
2. 选择 **"App 开发版"**（约 900MB）
3. 安装时勾选 **"5+App"** 和 **"uni-app"** 插件

#### 步骤 2: 导入项目

1. 打开 HBuilderX
2. 文件 → 导入 → 从本地目录导入
3. 选择 `E:\YM_MES\MES-tablet`
4. 等待依赖安装完成

#### 步骤 3: 配置 APP 设置

已自动配置好（manifest.json 已包含）：
- ✅ 蓝牙权限（BLUETOOTH / BLUETOOTH_ADMIN）
- ✅ 定位权限（Android 蓝牙扫描需要）
- ✅ 网络权限（INTERNET）

#### 步骤 4: 打包 APK

1. 菜单：发行 → 原生App-云打包
2. 选择平台：**Android**
3. 选择证书：
   - **开发测试**：使用 DCloud 公共证书（免费）
   - **正式发布**：需要自己申请签名证书
4. 点击 "打包"
5. 等待 3-5 分钟
6. 下载生成的 `.apk` 文件

#### 步骤 5: 安装到手机

1. 将 APK 传到手机（微信/QQ/数据线）
2. 手机上允许 "安装未知来源应用"
3. 安装并打开
4. **授予蓝牙和定位权限**（系统会弹出提示）
5. 测试蓝牙打印功能 ✅

## 🐛 常见问题排查

### 问题 1: APP 中搜索不到打印机

**可能原因**：
1. 打印机未开机或未进入配对模式
2. 手机蓝牙未开启
3. 未授予定位权限（Android 蓝牙扫描必须）
4. 打印机距离太远（建议 < 10米）

**解决方法**：
```bash
# 1. 确认打印机电源开启，指示灯闪烁
# 2. 手机设置 → 蓝牙 → 开启
# 3. APP设置 → 权限 → 允许定位
# 4. 将打印机靠近手机（1米内）
# 5. 重启APP再试
```

### 问题 2: 连接成功但打印失败

**检查项**：
- [ ] 打印机有纸吗？
- [ ] 打印机固件是否最新？
- [ ] 是否选择了正确的服务 UUID？

**调试方法**：
```javascript
// 在 bluetoothPrinter.js 的 sendPrintData 函数中添加日志
console.log('发送数据:', data)  // 查看原始数据
console.log('当前设备:', currentDevice)
console.log('特征值:', characteristic)
```

### 问题 3: Android 12+ 权限问题

**Android 12 新增了精确蓝牙权限**：

在 `android/app/src/main/AndroidManifest.xml` 添加：
```xml
<!-- Android 12+ 蓝牙权限 -->
<uses-permission android:name="android.permission.BLUETOOTH_SCAN" />
<uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />
```
