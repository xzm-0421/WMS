# WMS 仓储管理系统操作手册

> 版本 V2.0 ｜ 适用对象：仓库现场作业员、库管、计划员、生产建单人、系统管理员
> 本手册按当前系统实际菜单与界面文案编写，可直接用于现场培训与日常查阅。

---

## 1. 系统概述

### 1.1 系统组成

WMS 由三部分协同完成仓储作业：

- **Web 管理后台**：基础资料维护、用户与权限、库存查询、出入库记录、期初标签打印、看板报表。
- **PDA 移动端**：现场扫码作业，包括各类出入库通知单、盘点、移库、库存查询、条码校验等。
- **后端服务**：执行业务规则与库存记账，并与金蝶云星空企业版对接（查询源单、保存下推、提交审核）。

### 1.2 与金蝶云星空的分工

| 系统 | 职责 |
|------|------|
| 金蝶云星空 | 主数据源头（物料、仓库、供应商），业务单据的创建与最终账务 |
| WMS | 现场扫码执行、批次与库位管理、标签打印，并把执行结果回写金蝶 |

绝大部分出入库业务以**金蝶单据为源头**：PDA 拉取金蝶单据 → 扫码确认实物 → 回写实发数量并审核或下推。

### 1.3 登录信息

| 端 | 访问方式 | 账号 |
|------|------|------|
| Web | 浏览器打开 http://服务器地址:9980/ | admin / 123456（初始） |
| PDA | 安装 APK 后在登录页配置服务器地址 | 与 Web 同一套账号 |

> 提示：生产环境请立即修改初始密码。需要走金蝶「工作流审批」的账号（如生产补料、委外补料），必须先在 Web「用户管理」中绑定金蝶用户，否则提交会失败。

### 1.4 作业总原则

- **金蝶源单优先**：PDA 上看到的单据来自金蝶，不能在 PDA 端凭空新增业务单据。
- **分批提交**：同一行物料可以多次扫码、分批提交，界面会显示计划量、已处理量与可处理量。
- **单据独占锁**：一张单据同一时间只允许一个人操作，列表会显示「某某操作中」。
- **结果以弹窗为准**：提交成功会提示金蝶单号；失败时已处理数量自动回滚，可修正后重新提交。
- **先校验再扫码**：条码规则变更后，建议先用 PDA「条码校验」验证解析是否正确。

## 2. Web 管理后台

### 2.1 登录与界面

1. 浏览器打开系统地址，输入**用户名**、**密码**、**验证码**后点击「登 录」。
2. 登录后进入「工作台」，左侧为功能菜单（按角色权限显示），顶部显示当前用户。
3. 验证码点击即可刷新；登录失败时验证码会自动更换。

### 2.2 菜单一览

| 一级菜单 | 二级菜单 | 用途 |

| 基础数据 | 仓库信息 | 仓库主数据及金蝶仓库编码映射 |
| 基础数据 | 库位信息 | 仓库→区域→库位树形维护 |

### 2.3 系统管理

#### 2.3.1 用户管理

- **查询条件**：用户名、姓名。
- **主要操作**：「新增」建立账号；行内「编辑」「重置密码」「禁用/启用」「删除」。
- **绑定金蝶用户**：编辑用户时点击「金蝶用户」旁的搜索按钮，在「选择金蝶用户」对话框中按用户名称或电话查询后「选择」，也可「清除绑定」。

> 提示：生产备料的建单人识别、以及补料类单据的工作流审批，都依赖金蝶用户绑定，务必为相关账号完成绑定。

#### 2.3.2 角色管理

- **查询条件**：角色编码、角色名称。
- **主要操作**：「新增」「编辑」「删除」，以及仅超级管理员可用的「权限配置」。
- **权限配置**包含三部分：
  - 功能权限：按模块勾选可访问的菜单与按钮。
  - 数据范围：全部数据 / 指定仓库 / 本部门 / 本部门及以下。
  - 仓库范围：数据范围选「指定仓库」时，必须至少选择一个可访问仓库。

#### 2.3.3 业务规则与业务流程手册

- **业务规则**：以键值形式维护系统业务参数，逐行「保存」。
- **业务流程手册**：系统内置的只读文档，包含总体架构、编码规则、各业务模块说明与 PDA 功能对照。

### 2.4 基础数据

#### 2.4.1 产品/物料

- **查询条件**：物料编码、物料名称。
- **主要操作**：「新增」「编辑」「删除」「从金蝶同步」，行内「打印」可直接打印物料标签。
- **关键字段**：物料编码（留空自动生成）、物料名称、分类编码、单位、物料类型（原材料/成品/辅料）、是否批次管理、条码规则、状态。

> 提示：物料主数据以金蝶为准，日常请优先使用「从金蝶同步」，避免两边编码不一致。

#### 2.4.2 仓库信息

- **查询条件**：仓库编码、仓库名称。
- **主要操作**：「新增」「编辑」「从金蝶同步」。
- **关键字段**：仓库编码、仓库名称、**金蝶仓库编码**（需与金蝶 FStockId 一致，如 CK004）、仓库类型、地址、电话。

> 提示：金蝶仓库编码没有正确填写时，PDA 提交会因为找不到对应仓库而失败。

#### 2.4.3 库位信息

- 页面以「仓库 → 区域 → 库位」树形展示，可用「筛选仓库」下拉缩小范围。
- 选中仓库节点后可「新增区域」，选中区域节点后可「新增库位」。
- 库位类型分为：存储位、原料位、拣选位。

#### 2.4.4 条码规则

页面分为四个标签页：

| 标签页 | 用途 |
|------|------|
| 规则管理 | 维护条码拼接模板，支持「解析测试」；行内可「编辑」「版本」「禁用/启用」「删除」 |
| 条码生成 | 选择规则后按分段选取金蝶物料/批号/序列号，「生成条码」后可「打印标签」 |
| 条码存档 | 查询历史条码，可「补打」「打印」「预览」，也可「清理过期存档」 |
| 追溯查询 | 输入条码点击「追溯」，查看条码主档与流转记录 |

常用拼接模板：物料编码+批号+序列号、包装条码+批号、物料编码+批号、物料编码+序列号、自定义分段。

### 2.5 出入库管理

#### 2.5.1 入库单

- **查询条件**：单号、仓库、状态（草稿/待审核/入库中/已完成/已取消）。
- **主要操作**：「新建入库单」，行内「详情」「打印」；详情抽屉内按状态显示「提交」「审核」「反审核」「取消」。
- 新建时可选择采购入库、生产入库、退货入库，明细支持「添加行」与「删除」。

#### 2.5.2 PDA入库记录

- **查询条件**：记录号、物料、仓库、状态、同步状态（待同步/已同步/同步失败）。
- **主要操作**：行内「详情」「打印」「审核」「冲销」「重同步」。
- 详情中可查看金蝶单号、同步消息与完整的金蝶同步日志。

> 提示：同步失败时先在详情里看同步消息定位原因（多为仓库映射、批次或数量问题），修正后再点「重同步」。

#### 2.5.3 收料入库批次

- 展示收料通知单的分批入库记录，可按收料单号与金蝶状态查询。
- 行内「详情」可查看入库明细与同步日志，「同步金蝶」用于失败后重试。

#### 2.5.4 PDA出库记录

- **查询条件**：批次号、单据号、单据类型、同步状态。
- 行内「详情」可查看库存扣减明细，「同步金蝶」用于失败重试。

### 2.6 库存管理

#### 2.6.1 实时库存

页面包含三个标签页：

- **实时库存**：按仓库、物料编码查询，显示物料编码、标签号、名称、规格、可用量、单位、仓库、生产日期、库存数量。
- **库存流水**：按仓库、物料、类型（入库/出库/移库/调整）查询，显示变动前后数量、来源单号、操作人与时间。
- **库存预警**：按仓库查询低库存、临期、超储三类预警。

#### 2.6.2 库存抽检

- 「制定抽检计划」创建计划，行内「抽检清单」查看待抽检明细。
- 抽检结果按「合格/不合格」录入后「提交」，右侧「异常预警」面板汇总异常项。

### 2.7 数据看板与报表

- **工作台**：今日入库单数、今日出库单数、库存 SKU 数、待处理任务数，以及近 7 天出入库趋势、待处理任务占比、库存预警与最近操作日志。
- **仓库统计看板**：当前库存总量、低库存预警 SKU、出入库趋势与仓库空间使用率。
- **报表概览**：入库统计、出库统计柱状图与低库存预警报表。

## 3. 物料标签打印

物料标签统一使用 **100×70mm（10×7cm）** 标签纸，分为「厂内标签」和「来料标签」两种版式。

### 3.1 两种版式对照

| 项目 | 厂内标签 | 来料标签 |
|------|------|------|
| 抬头 | 东莞市艾迪富精密金属科技有限公司 + 物料标签 | 物料标签 |
| 往来单位 | 客户名称（填简称） | 供应商名称（填简称） |
| 辅助编号 | 板号 | 包装号 |
| 公共字段 | 生产日期、物料编码、数量、物料名称、规格型号、批次号 | 同左 |
| 二维码 | 右侧，内容为条码规则生成的追溯码 | 同左 |

两种版式的字段排布均为左侧八格信息、右侧二维码，纸张与边距完全一致，因此可以混用同一卷标签纸。

> 提示：批次号建议按「年月日+4 位流水」编制；厂内标签的板号常与批次组合使用，便于按板追溯。

### 3.2 打印机与纸张设置

1. 打印方向选择**纵向**。
2. 打印机驱动中的纸张尺寸设为**宽 100mm × 高 70mm**。
3. 缩放选择**实际大小**（不要选「适应页面」，否则尺寸会走样）。
4. 关闭浏览器打印对话框中的「页眉和页脚」。

### 3.3 新建单张标签

进入「基础数据 → 期初库存」，点击右上角「新建打印」：

1. 选择**标签类型**：厂内 或 来料。
2. 填写**客户简称**（厂内）或**供应商简称**（来料），选填。
3. 填写**板号**（厂内）或**包装号**（来料），选填。
4. 选择**物料**（必填，从物料信息中选择），填写批次号、生产日期、数量、入库单位、计价单位。
5. 选择**条码类型**（二维码 QR / Code128 / Code39），默认 QR。
6. 确认**标签纸规格**为 10×7cm，设置**打印份数**。
7. 点击「创建并预览」，在弹出的预览窗口确认无误后打印。

### 3.4 Excel 批量导入

1. 点击「下载模板」，得到含表头与示例行的 Excel。
2. 按模板填写，从第 2 行开始，可删除示例行。关键列说明：

| 列名 | 必填 | 说明 |
|------|------|------|
| 物料编码 | 是 | 必须已存在于「产品/物料」中 |
| 仓库编码 / 仓库名称 | 否 | 可二选一或同时填写 |
| 批次号 | 否 | 批次管理物料建议填写 |
| 生产日期 | 否 | 格式 yyyy-MM-dd，不填则打印当天 |
| 数量 | 否 | 支持小数 |
| 打印份数 | 否 | 正整数，默认 1 |
| 标签类型 | 否 | 填「厂内」或「来料」，空则默认厂内 |
| 客户/供应商 | 否 | 厂内填客户简称，来料填供应商简称 |
| 板号 | 否 | 厂内标签使用 |
| 包装号 | 否 | 来料标签使用 |

3. 点击「导入」上传文件，系统提示成功导入的条数。
4. 需要留档时点击「导出」下载当前查询结果。

### 3.5 预览、打印与批量打印

- 行内「预览」只打开预览窗口，不弹出打印对话框，适合核对版式。
- 行内「打印」直接弹出打印对话框。
- 勾选多行后使用「批量预览」或「批量打印」，可一次输出多张。
- 行内「参数」可单独调整该任务的标签纸规格、纸宽纸高、打印份数与条码类型。

> 提示：批量打印要求所选任务的标签尺寸完全一致，否则系统会提示「所选任务标签尺寸不一致」。

### 3.6 金蝶推送打印

金蝶云星空可通过二开按钮直接推送标签打印任务，WMS 返回打印地址后由金蝶客户端打开浏览器自动打印。

- 未指定标签类型时，金蝶推送默认按**来料标签**渲染，期初导入与手工新建默认按**厂内标签**渲染。
- 金蝶端可在请求中传入 `labelFormat`、`partnerName`、`boardNo`、`packageNo` 指定版式与专有字段。
- 详细接口与字段说明见《金蝶标签打印对接说明》。

## 4. PDA 操作总则

### 4.1 安装与登录

1. 安装 PDA 应用后首次打开，在登录页顶部点击「服务器」右侧的齿轮图标，填写后端地址。
2. 输入**工号**与**密码**，点击「登录」。
3. 登录后底部出现四个标签：**主页**、**入库**、**出库**、**我的**。

### 4.2 主页与快捷入口

主页顶部显示问候语与**待办任务合计**，下方为三个可点击的待办卡片（待入库、待出库、待盘点），再往下是快捷功能宫格：

| 分组 | 宫格入口 |
|------|------|
| 出入库 | 入库业务、出库业务 |
| 拣货相关 | 扫码拣货、领料确认、车间退库、生产退料、生产补料、委外补料、委外退料、生产退库 |
| 其他业务 | 销售退货、盘点、移库 |
| 工具 | 库存查询、条码校验、批次追溯、消息 |

「入库」「出库」标签页与「入库业务」「出库业务」宫格进入的是同一个单据类型选择页（Hub），从中选择具体单据类型后进入列表。

### 4.3 扫码技巧

- **红外扫码枪**：无需点击输入框，页面就绪后直接扫码即可自动录入，界面会提示「扫码枪已就绪，扫描后自动录入」。
- **手工输入**：在列表页的搜索框输入单号后点击「打开」或按键盘确认键。
- **输入数量时**：点击数量输入框后系统会暂停扫码框自动抢焦点，改完数量再扫下一个标签即可。
- **单据二维码**：直接扫描单据上的二维码可跳过列表，直接进入该单据的扫码页。

### 4.4 仓库选择

入库与退料类扫码页顶部有仓库选择区，有两种模式：

- **自动分配**：按物料仓库或生产订单仓库自动分配，跳过未分配仓，适合大多数场景。
- **手动选仓**：从下拉列表中指定仓库，列表可点「刷新」重新拉取。

### 4.5 单据独占锁

- 进入单据明细即自动占用该单据，离开页面自动释放，服务端锁有效期为 3 分钟。
- 单据被他人占用时，列表会显示「某某操作中」，强行进入会提示「单据正由【某某】操作中，请稍后再试」并自动返回。

> 提示：如果同事异常退出导致单据被锁，等待 3 分钟锁自动过期即可重新进入。

### 4.6 消息中心

- 主页宫格「消息」进入，顶部显示「未读消息: N」，可点击「全部已读」。
- 目前主要用于生产备料完成通知，标题为「生产备料完成，请到仓库领料」。
- 点击生产备料类消息会直接跳转到对应领料单的扫码页，供建单人确认领料。

### 4.7 我的

「我的」标签页显示姓名、工号、角色，以及用户 ID、绑定仓库、设备编号、离线队列、当前服务器等信息。

- 「更新」：进入检查更新页，自动检测最新版本，可「重新检测」或「立即更新」。
- 「系统设置」：配置服务器地址、查看设备信息，并在「账号安全」区修改密码（原密码、新密码、确认新密码 →「保存密码」）。
- 「退出登录」：确认后返回登录页。

## 5. PDA 入库业务

### 5.1 单据类型对照

| PDA 单据类型 | 金蝶源单 | 扫描的单据状态 |
|------|------|------|
| 收料通知单 | PUR_ReceiveBill | 已审核的收料通知单 |
| 生产汇报入库 | PRD_MORPT | 已审核的生产汇报单 |
| 生产退料 | PRD_ReturnMtrl | 未审核的生产退料单 |
| 委外退料 | SUB_RETURNMTRL | 未审核的委外退料单 |
| 其他入库单 | STK_MISCELLANEOUS | 未审核的其他入库单 |
| 销售退货通知单 | SAL_RETURNNOTICE | 已审核的退货通知单 |

### 5.2 通用入库流程

所有入库单据都遵循「列表 → 扫码 → 分批提交」的模式：

1. 从「入库业务」中选择单据类型，进入单据列表。
2. 扫描单据二维码或搜索单号后点「打开」，进入扫码页。
3. 选择仓库（自动分配或手动选仓）。
4. 逐个扫描物料标签，系统自动匹配对应行并累加数量。
5. 需要修改时，点击该行的数量输入框直接改成实际数量。
6. 核对无误后点击底部提交按钮，等待金蝶返回结果。

> 提示：一张单可以分多次提交。提交后列表状态会变为「进行中」，剩余数量下次继续扫。

### 5.3 收料通知单（采购入库）

采购到货的主流程，注意三点：

- 列表只显示已审核且仍有未收数量的收料通知单。
- 系统会按检验要求过滤行，免检物料可直接入库。
- 提交后在 Web「收料入库批次」中可以查看分批入库记录与金蝶同步状态。

### 5.4 生产汇报入库

- 扫描的是**已审核**的生产汇报单。
- 车间信息从生产订单读取；未分配仓库的行会被跳过。

### 5.5 生产退料 / 委外退料

- 扫描的是**未审核**的退料单，PDA 确认实退数量后回写并审核。
- 从主页宫格「生产退料」「委外退料」直接进入。

### 5.6 销售退货与其他入库

- **销售退货通知单**：扫已审核的退货通知，确认实退数量后入库。
- **其他入库单**：扫未审核的其他入库单，用于盘盈、领用退回等场景。

## 6. PDA 出库业务

### 6.1 单据类型对照

| PDA 单据类型 | 金蝶源单 | 说明 |
|------|------|------|
| 生产备料 | PRD_PickMtrl | 拉审核中的领料单，仓管备货、建单人扫单审核 |
| 生产补料 | PRD_FeedMtrl | 扫未审核补料单，提交走工作流审批 |
| 委外领料 | SUB_PickMtrl | 扫未审核的委外领料单 |
| 委外补料 | SUB_FEEDMTRL | 扫未审核补料单，提交走工作流审批 |
| 销售发货通知单 | SAL_DELIVERYNOTICE | 扫已审核发货通知，确认后下推销售出库并审核 |
| 生产退库 | PRD_RetStock | 扫未审核的生产退库单 |
| 其他出库单 | STK_MisDelivery | 扫未审核的其他出库单 |
| 采购退料单 | PUR_MRB | 扫未审核的采购退料单 |

### 6.2 生产备料（两段式）

生产备料分为「仓管备货」和「建单人领料审核」两个阶段，避免仓管代替建单人确认领料。

#### 阶段一：仓管备货

1. 主页选择「出库业务 → 生产备料」，或直接扫描领料单二维码。
2. 列表只显示金蝶中**审核中**的生产领料单，每行显示领料单号、车间、建单人、物料项数与已勾数量。
3. 打开单据后逐个扫描物料标签，界面显示计划、已领、可领数量，可在「本次领取」中修改实发数量。
4. 备齐后点击底部「备货完成」。

点击「备货完成」后系统会：将单据状态置为**已备货**、识别金蝶建单人并推送 PDA 消息、释放单据锁，界面提示「已备货完成，已通知建单人」。

> 提示：至少要有一行填写了数量才能点「备货完成」，否则会提示「请先扫码或填写数量后再备货完成」。

#### 阶段二：建单人领料审核

1. 建单人收到消息「生产备料完成，请到仓库领料」，点击消息直接进入该单据。
2. 也可以到仓库直接扫描领料单二维码进入。
3. 页面显示「已备货，待建单人扫码领料」，底部按钮变为「确认领料并审核」。
4. 确认后系统把实发数量回写金蝶并提交审核。

> 提示：只有金蝶建单人对应的 WMS 账号（或超级管理员）能执行确认，其他人会收到「仅领料单建单人「某某」可扫码确认领料并审核」的提示。因此建单人账号必须先完成金蝶用户绑定。

#### 状态说明

| 列表状态 | 含义 |
|------|------|
| 待备料 | 尚未开始扫码 |
| 扫码中 | 仓管正在备货 |
| 已备货 | 备货完成，等待建单人确认 |
| 已出完 | 已全部出库完成 |

### 6.3 生产补料 / 委外补料

- 列表显示**未审核**的补料单。
- 明细行**必须扫描物料标签**才能勾选，不允许手工勾选，以确保实物核对。
- 数量区显示计划、已补、可补，可修改「本次补料」。
- 底部点击「确认补料」提交，单据进入金蝶**工作流审批**。

> 提示：走工作流审批的账号必须绑定金蝶用户，否则提交时会因找不到审批人而失败。

### 6.4 销售发货

- 扫描**已审核**的发货通知单。
- 确认发货数量后提交，系统自动**下推生成销售出库单并审核**。

### 6.5 委外领料与其他出库

- **委外领料**：扫未审核的委外领料单，确认实发数量后回写审核。
- **生产退库 / 其他出库 / 采购退料**：均为扫未审核单据，确认数量后回写审核，操作方式与通用出库一致。

## 7. PDA 其他作业

### 7.1 盘点作业

1. 主页宫格「盘点」进入盘点任务列表。
2. 选择任务后进入盘点扫码页，逐个扫描库位与物料标签。
3. 录入实盘数量，系统自动计算与账面的差异。
4. 提交后由 Web 端复核处理差异。

### 7.2 库存查询

主页宫格「库存查询」，支持按物料或扫描标签查询，显示各仓库、批次的当前库存与可用量。

### 7.3 移库

主页宫格「移库」，扫描物料标签后指定目标库位完成库内转移，库存流水中会记录为「移库」类型。

### 7.4 条码校验

主页宫格「条码校验」，扫描任意条码即可查看系统解析出的物料编码、批次、序列号等分段结果，用于排查扫码异常。

### 7.5 批次追溯

主页宫格「批次追溯」，输入或扫描批次条码，查看该批次的完整流转记录。

### 7.6 扫码拣货 / 领料确认 / 车间退库

这三个功能面向车间协同场景，均从主页宫格进入，操作方式与通用扫码流程一致：扫描单据 → 扫描物料 → 确认数量 → 提交。

## 8. 典型业务场景

### 8.1 采购收货入库

1. 采购员在金蝶创建并审核收料通知单。
2. 货到仓库，库管在 PDA 选择「入库业务 → 收料通知单」。
3. 扫描单据二维码打开单据，选择收货仓库。
4. 逐箱扫描物料标签，核对数量。
5. 提交，等待金蝶返回入库单号。
6. 如需贴标，在 Web「期初库存」按来料标签版式打印并贴于物料外包装。
7. 在 Web「收料入库批次」确认同步状态为「已同步」。

### 8.2 生产备料到领料

1. 计划员在金蝶创建生产领料单并提交（状态为审核中）。
2. 仓管在 PDA「出库业务 → 生产备料」中看到该单。
3. 仓管扫码备货，逐行确认实发数量后点「备货完成」。
4. 建单人收到 PDA 消息，到仓库点击消息或扫描领料单二维码。
5. 建单人点击「确认领料并审核」，数量回写金蝶并完成审核。
6. 在 Web「PDA出库记录」核对同步状态。

### 8.3 销售发货

1. 销售在金蝶创建并审核发货通知单。
2. 库管在 PDA「出库业务 → 销售发货通知单」中打开该单。
3. 扫描待发货物料，确认数量后提交。
4. 系统自动下推销售出库单并审核，PDA 提示金蝶单号。

### 8.4 期初库存建账与贴标

1. 在 Web「期初库存」点击「下载模板」。
2. 按实盘结果填写 Excel，标签类型填「厂内」，补充客户简称与板号。
3. 点击「导入」上传。
4. 勾选导入的记录，点「批量预览」核对版式。
5. 确认无误后「批量打印」，按 100×70mm 标签纸打印并贴标。

## 9. 常见问题

| 现象 | 原因与处理 |
|------|------|
| PDA 提示「金蝶未启用」 | 后端未启用金蝶集成或配置缺失，联系管理员检查服务端配置后重启服务 |
| 提示「当前尝试登录的数据中心无法获取到」 | 金蝶数据中心账套参数缺失或填错，需管理员核对后端金蝶连接配置 |
| 单据列表里看不到应有的单据 | 检查单据在金蝶中的状态是否符合要求（各类型要求见 5.1、6.1），以及是否已被全部处理完 |
| 提示「单据正由【某某】操作中」 | 单据被他人占用，等待对方退出或等锁 3 分钟自动过期 |
| 扫码没反应 | 确认扫码页已就绪；若刚编辑过数量，先点一下扫码框恢复焦点；必要时用「条码校验」验证条码本身 |
| 提交失败提示仓库相关错误 | 检查 Web「仓库信息」中金蝶仓库编码是否与金蝶一致 |
| 补料提交失败提示审批人问题 | 该账号未绑定金蝶用户，到 Web「用户管理」编辑用户完成绑定 |
| 生产备料无法确认领料 | 当前账号不是该单据的金蝶建单人，需由建单人本人操作 |
| 标签打印尺寸不对 | 打印方向选纵向、驱动纸张设 100×70mm、缩放选实际大小 |
| 批量打印提示尺寸不一致 | 所选任务标签规格不同，请分批选择相同规格的任务 |
| 同步状态一直是「同步失败」 | 在记录详情中查看同步消息定位原因，修正后点「重同步」或「同步金蝶」 |
