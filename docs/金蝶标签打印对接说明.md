# 金蝶云星空 → WMS 物料标签打印（二开按钮）

金蝶表单工具栏/分录按钮点击后，调用 WMS 接口创建打印任务，并在浏览器打开 WMS 打印页（`print-designer`），无需登录 WMS。

## 1. 配置

`application-dev.yml` / 生产环境：

```yaml
kingdee:
  cloud:
    # 可选；配置后请求头必须带 X-Kingdee-Api-Key
    print-api-key: "your-secret"
    # 金蝶客户端能访问的 WMS 根地址（必配，用于拼绝对打印 URL）
    print-public-base-url: http://192.168.0.10:9980
```

也可用环境变量：`WMS_PUBLIC_BASE_URL`。

## 2. 接口一览（均免登录）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/integration/kingdee/label-print` | 创建单张标签任务 |
| POST | `/api/v1/integration/kingdee/label-print/batch` | 批量创建 |
| GET | `/api/v1/integration/kingdee/label-print/jobs/{jobId}/data` | 打印数据 |
| POST | `/api/v1/integration/kingdee/label-print/jobs/{jobId}/open` | 标记已打开 |
| POST | `/api/v1/integration/kingdee/label-print/jobs/{jobId}/printed` | 打印结果回调 |
| GET | `/api/v1/integration/kingdee/label-print/jobs/{jobId}/open-print` | 302 跳转打印页 |
| GET | `/api/v1/integration/kingdee/label-print/health` | 健康检查 |

请求头（若配置了 api-key）：

```
X-Kingdee-Api-Key: your-secret
Content-Type: application/json
```

### 单张请求体示例

```json
{
  "sourceBillNo": "CGSL25080001",
  "materialCode": "MAT-10001",
  "materialName": "电阻 10K",
  "specification": "10KΩ ±1%",
  "batchNo": "B20260817",
  "productionDate": "2026-08-17",
  "quantity": 100,
  "unitCode": "PCS",
  "warehouseCode": "CK004",
  "copies": 1,
  "barcodeType": "QR",
  "labelFormat": "INCOMING",
  "partnerName": "某某供应商",
  "packageNo": "PKG001"
}
```

标签版式（100×70mm）：

| labelFormat | 说明 | 特有字段 |
|-------------|------|----------|
| `FACTORY` / 厂内 | 抬头含公司名；显示客户名称、板号 | `partnerName`、`boardNo` |
| `INCOMING` / 来料 | 标题「物料标签」；显示供应商名称、包装号 | `partnerName`、`packageNo` |

不传 `labelFormat` 时：金蝶推送默认 `INCOMING`，期初/手工默认 `FACTORY`。
### 成功响应关键字段

- `printUrl`：相对路径  
- `absolutePrintUrl`：绝对地址（含 `autoPrint=1`），金蝶用 `Process.Start` / `WebBrowser` / `Shell` 打开即可

## 3. 金蝶二开按钮（推荐流程）

1. 按钮插件读取当前分录：物料编码、名称、规格、批号、数量、仓库等  
2. `HTTP POST` 到 WMS 创建任务  
3. 取返回的 `absolutePrintUrl`，用系统默认浏览器打开  

### C# 插件伪代码（WebAPI 插件 / 表单插件）

```csharp
// 1) 组装 JSON（示意）
var body = new {
    sourceBillNo = this.View.Model.GetValue("FBillNo")?.ToString(),
    materialCode = row["FMaterialId"]?.Number, // 按实际字段取
    materialName = row["FMaterialId"]?.Name,
    specification = row["FMateriaModel"]?.ToString(),
    batchNo = row["FLot"]?.Number,
    quantity = row["FQty"],
    unitCode = row["FUnitID"]?.Number,
    warehouseCode = row["FStockId"]?.Number,
    copies = 1,
    barcodeType = "QR"
};

// 2) POST http://WMS主机:9980/api/v1/integration/kingdee/label-print
// Header: X-Kingdee-Api-Key / Content-Type: application/json

// 3) 解析 data.absolutePrintUrl，打开浏览器
System.Diagnostics.Process.Start(new System.Diagnostics.ProcessStartInfo {
    FileName = absolutePrintUrl,
    UseShellExecute = true
});
```

### 仅跳转（已有 jobId）

直接打开：

```
http://WMS主机:9980/api/v1/integration/kingdee/label-print/jobs/{jobId}/open-print?autoPrint=true
```

## 4. 批量打印

`POST /api/v1/integration/kingdee/label-print/batch`

```json
{
  "autoPrint": true,
  "lines": [
    { "materialCode": "A", "materialName": "物料A", "batchNo": "B1", "quantity": 10 },
    { "materialCode": "B", "materialName": "物料B", "batchNo": "B2", "quantity": 20 }
  ]
}
```

返回 `printUrls[]`；可循环打开，或先打开 `firstPrintUrl`。

## 5. 注意

1. **物料**：WMS 未同步该物料时，只要请求带了 `materialName`/`specification` 也可建任务并打印。  
2. **网络**：金蝶客户端所在电脑必须能访问 `print-public-base-url`。  
3. **前端**：修改 `print-designer` 后需重新 `npm run build`，并执行 `scripts/sync-web-to-backend.bat`。  
4. **浏览器弹窗**：若被拦截，请允许自动打开窗口或改用系统浏览器打开 URL。  
5. Web「期初库存」菜单仍可手工维护/打印，与金蝶推送任务共用 `label_print_job` 表（`sourceType=KINGDEE`）。
