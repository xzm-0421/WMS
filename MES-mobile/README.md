# MES-mobile

星运维 **手机移动端**（uni-app），独立于 Web 管理后台、PDA 仓储终端和 MES-tablet 工业平板。

当前为界面骨架：登录、改密、首页、服务、我的。业务接口后续接入。

## 启动

```bash
cd MES-mobile
npm install
npm run dev:h5
```

浏览器访问 **http://localhost:5176**（建议用手机宽度预览）。

真机请用 HBuilderX 打开 `MES-mobile` 目录。

## 页面

| 页面 | 说明 |
|------|------|
| 登录 | 账号 / 密码 |
| 首页 | 工单统计、快捷入口、待办列表 |
| 服务 | 移动工单服务、统计分析 |
| 我的 | 资料、改密、退出 |
| 修改密码 | 复杂度校验（本地） |

底部三个 Tab：首页 / 服务 / 我的。
